BikeRent is a comprehensive bike rental platform featuring a web interface and a native Android application. It allows users to find, rent, and manage bike rentals seamlessly.

## Project Architecture

The project is a monorepo composed of three main parts:

*   **Backend (`/backend`):** A robust REST API built with **Spring Boot** (Java). It handles business logic, user management, and rental data. Uploaded photos from users are stored in an external directory on the file system for persistence.
*   **Frontend (`/frontend`):** A modern single-page application built with **Angular**. It provides a user-friendly web interface for interacting with the platform.
*   **Mobile (`/android`):** A native **Android** application developed in **Kotlin**. It features map-based tracking of bikes and available parking spots using the [osmdroid](https://github.com/osmdroid/osmdroid) library.

## Key Features

- **Interactive Map:** Find available bikes and designated parking spots in real-time.
- **Rental Management:** Users can view their active rentals and rental history.
- **Photo Uploads:** At the end of a ride, users can upload photos of the parked bike.
- **User Authentication:** Secure registration and login for users.

## Getting Started

To get the full application running, you will need to start each component separately.

### Backend (Spring Boot)

The backend server is required for the frontend and mobile apps to function.

1.  **Navigate to the backend directory:**
    ```bash
    cd backend
    ```

2.  **Run the Spring Boot application using the Maven wrapper:**
    *   On macOS/Linux:
        ```bash
        ./mvnw spring-boot:run
        ```
    *   On Windows:
        ```bash
        mvnw.cmd spring-boot:run
        ```
    The server will start on the port configured in `application.properties` (default is 8080).

### Frontend (Angular)

The web application provides the main user interface.

1.  **Navigate to the frontend directory:**
    ```bash
    cd frontend
    ```

2.  **Install project dependencies:**
    ```bash
    npm install
    ```

3.  **Start the Angular development server:**
    ```bash
    ng serve
    ```
    Navigate to `http://localhost:4200/`. The app will automatically reload if you change any of the source files.

### Mobile (Android)

The native Android app offers a mobile-first experience.

1.  Open the `/android` directory in **Android Studio**.
2.  Let Android Studio sync the Gradle project.
3.  Build the application using the `Build > Make Project` menu or by running the default `app` configuration.
4.  Run the application on an Android emulator or a physical device.
